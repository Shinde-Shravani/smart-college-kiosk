# 🎨 Frontend - Smart College Kiosk

## What is this?
This is the frontend (user interface) part of my Smart College Kiosk project. It displays:
- Welcome screen for students and parents
- Chat interface for asking questions
- Staff directory with photos
- Campus locations and maps
- Branch recommendation form

## Technology Stack
- **Language:** JavaScript
- **Framework:** React.js (learning this)
- **Styling:** CSS
- **HTTP Client:** Axios (for calling backend API)
